Theorem \ref{thm:Theorem:1.3} provides the criteria we use to confirm that singularity formation occurs in Euler as $\alpha\rightarrow 0$. First we check that condition (\ref{eq:eta:0:condition}) is satisfied, then we check that (\ref{eq:alpha:sup}) is satisfied. It is not necessarily clear whether or not the value used in each criterion is converging to zero or to some small positive value. In order to make this determination we use the method of \cite{larios_computational_2018}, which proposes the following ansatz,
\begin{equation}
\sup_{t\in[0,T^*]}\|\nabla\ua(t)\|_{L^2} \approx \mathcal{O}(\alpha^p),
\end{equation}
for $T^* > 0$ sufficiently large and for some power $p$. From Theorem \ref{thm:Theorem:1.3}, if there exists a finite time $T^*>0$ such that
\begin{equation}
\limsup_{\alpha\rightarrow 0}\left( \alpha^2\sup_{t\in[0,T^*]}\|\nabla\ua(t)\|_{L^2}^2\right) > 0.
\end{equation}
then $\u$ develops a singularity in the interval $[0,T^*]$. From this ansatz, in order for singularity formation to occur, we must have $p\leq -1$.
